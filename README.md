# Sistema de Gestión Integral - Concejo Municipal de Potosí

Sistema institucional desarrollado para apoyar la gestión administrativa, documental y Legislativa del Concejo Municipal de Potosí.

## Módulo inicial

El primer módulo del sistema será el de **Gestión Documental**, orientado al registro, seguimiento, derivación, búsqueda y archivo de documentos institucionales.

## Tecnologías

- PHP / Laravel
- Vue.js
- PostgreSQL
- Git / GitHub

## Objetivo

Centralizar y optimizar la gestión de documentos, trámites y procesos internos del Concejo Municipal de Potosí, permitiendo un mejor control, seguimiento y acceso a la información institucional.

## Estado del proyecto

Proyecto en etapa inicial de planificación y desarrollo.

## Equipo de desarrollo

Unidad de Sistemas  
Concejo Municipal de Potosí

## Repositorio

Este repositorio será utilizado para controlar las versiones del sistema, coordinar el trabajo del equipo de desarrollo y preparar los despliegues hacia servidores de prueba y producción.
